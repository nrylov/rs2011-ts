Commands

sdk.* provides state queries and direct client actions. bot.* provides higher-level actions. Run game actions sequentially; inspect returned evidence and fresh game messages. A sent packet alone does not prove the server applied an action.

Timeout parameters use milliseconds. MCP execute_code.timeout uses seconds. Default values below come directly from the implementation.

“Read-only · gateway” works for observers. “Control · gateway” requires the controller. “Local SDK only” is unavailable through gateway/MCP dispatch. “Remote client helper” runs in the agent’s gateway SDK. Where signatures differ, expand the remote signature. Examples with item names require the matching item and game context.
