# Shared development instructions

Read [AGENTS.md](AGENTS.md), [PROJECT_CONTEXT.md](PROJECT_CONTEXT.md) and
[TODO.md](TODO.md) before working. These files are the canonical shared context
for Claude, Codex and human contributors; keep them current instead of creating
a separate Claude-only project history.

Inspect Git status and relevant source to verify notes. Coordinate file ownership
with other active agents. After meaningful work, update the shared backlog and
record what is implemented, checked, deployed and still pending. Never copy
credentials or private runtime/account data into these notes.
